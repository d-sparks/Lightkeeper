Done. Here's a summary of what was implemented:

### Three new legendary sol grid components:

**1. Sol Teleport Emitter** (`sol_teleport_chip`)
- Ability type component, costs 200 energy, 3s cooldown, slot 4
- Mouse click/right-click: teleports to the cursor position (capped at 20 tiles)
- Shift+ability / gamepad: teleports in the aim direction ~12 tiles (~3/4 screen)
- Server validates destination against walls (walks back along the line to find valid position) and resolves collisions

**2. Uranium Generator** (`uranium_generator_chip`)
- New "generator" component type — passive 75 energy/sec regen
- Regen is applied every server tick alongside existing solar panel regen

**3. Advanced Rechargeable Battery** (`advanced_rechargeable_battery_chip`)
- New "battery" component type — adds 5000 to max energy capacity
- Capacity is recalculated whenever abilities are rebuilt (equip/grid change)

### Engine changes:
- Two new sol grid cell types: `generatorId` and `batteryId` (place, remove, rebuild, client sync)
- `_rebuildAbilities` scans for generators and batteries in the grid
- Client sends `targetX`/`targetY` with ATTACK messages when mouse-aimed (for teleport)
- Sol grid UI renders generators in yellow and batteries in blue
- All three items are legendary rarity, obtainable via the checkpoint editor for testing
