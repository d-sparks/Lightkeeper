Done. Here's what was added:

**Server (`server/checkpoint-api.js`)**:
- `GET /api/checkpoint/items` — returns all item types from content (id, name, type, rarity), sorted alphabetically
- `POST /api/checkpoint/give-item` — accepts `{ playerId, itemType, count }`, adds items to the player's inventory and syncs the client. Silicon is special-cased to go to automation resources instead.

**Content loader (`server/content-loader.js`)**:
- Added `getAllItems()` method (follows the same pattern as `getAllQuests()` and `getAllDungeons()`)

**Checkpoint UI (`checkpoint/app.js`)**:
- New `GiveItem` component with dropdowns for player and item type, a count input, and a "Give" button
- Panel appears between "Player Stats" and "Saved Checkpoints" in the checkpoint tool
- Items list is fetched once on load from the new API endpoint
