## Committed: `2ee4afa` — Add automated content testing: static validator + headless simulator

### `tools/content-validator.js` (Phase 1)
Static content analyzer that validates all JSON cross-references without running the game engine:
- **Cross-reference validation** — monster/NPC/item/tileset/exit IDs all resolve correctly
- **Exit graph reachability** — BFS from spawn room proves every dungeon is reachable
- **Bidirectional exit consistency** — flags one-way exits as warnings
- **Exit tile bounds** — ensures exit positions are within dungeon dimensions
- **Flag dependency analysis** — every checked flag must be settable somewhere; unused flags warned
- **Item flow validation** — quest-required items must be obtainable from spawns or triggers
- **Quest completability** — target rooms are reachable from spawn
- **Output**: human-readable report or `--json` for CI; exit code 1 on errors

### `tools/headless-sim.js` (Phases 2–7)
Full headless game simulator with a bot player:
- **Engine harness** — imports real `GameLoop`, `ContentLoader`, scripting stack; captures messages instead of WebSocket sends; drives with synchronous `update(dt)` loop at 1000x+ speed
- **Bot navigation** — A* pathfinding on tile grids; exit graph BFS for inter-room routing; stuck detection (300 ticks)
- **Bot combat** — ranged kiting, melee closing, ability usage off cooldown, health potion healing at 30% HP
- **Bot interaction** — NPC talk, item pickup, door opening, choice menu auto-selection, sol grid placement
- **Quest walkthrough** — loads quest steps, resolves NPC-to-flag mapping by scanning triggers, decomposes steps into navigate/interact/wait goals
- **Side quest coverage** — dependency DAG with topological sort; all 10 quests ordered by prerequisites
- **Explore mode** — BFS all rooms from spawn, interact with every NPC/item in each room
- **Run modes**: `--mainline`, `--all-quests`, `--quest=<id>`, `--explore`, `--json`
- **Output**: human-readable summary with quest progression, combat stats, exploration coverage, soft lock detection; or JSON for CI
